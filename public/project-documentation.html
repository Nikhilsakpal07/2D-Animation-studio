1. Executive Summary & System Overview

The 2D Animation Studio & Computer Graphics Laboratory is a production-grade web application built in Next.js 16, TypeScript, and the HTML5 Canvas API. Designed to unite academic computer graphics theory with an intuitive animation tool, the platform is divided into four distinct, full-featured subsystems:

  • Visual Creation Studio & Graphics Lab: Interactive pixel-grid drawing visualizer, custom animated scenic backdrop generator, and pre-rigged character template library.
  • Stage Canvas Architecture & Grouping: Infinite pan/zoom canvas, affine viewport transformation engine, rubber-band marquee selection, and hierarchical object grouping.
  • 3×3 Homogeneous Matrices & Skeletal Rigging: Real-time 3×3 matrix inspector, custom joint pivot points, and hierarchical Forward Kinematics.
  • 24 FPS Animation Timeline, Audio & Export Pipeline: Multi-track 24 FPS keyframe sequencer with parametric easing, 100% offline procedural Web Audio synthesizer, client-side GIF89a LZW encoder, and Firebase Cloud Firestore dual-sync.

3. Key Mathematical Formulations & Derivations

3.1 Bresenham's Integer Line Drawing Algorithm

Eliminates floating-point division and rounding calls by deriving an integer decision parameter $err = \Delta x - \Delta y$:

p_0 = 2Δy - Δx
If p_k < 0 : Plot(x_k + 1, y_k), p_{k+1} = p_k + 2Δy
If p_k ≥ 0 : Plot(x_k + 1, y_k + 1), p_{k+1} = p_k + 2Δy - 2Δx

3.2 Midpoint Circle Algorithm & 8-Way Symmetry

Evaluates midpoint $M(x_k + 1, y_k - 0.5)$ against implicit circle $f(x, y) = x^2 + y^2 - r^2$, yielding:

p_0 = 5/4 - r ≈ 1 - r (for integer arithmetic)
If p_k < 0 : p_{k+1} = p_k + 2x_{k+1} + 1
If p_k ≥ 0 : p_{k+1} = p_k + 2x_{k+1} + 1 - 2y_{k+1}

Plotting $(x, y)$ instantly generates 8 symmetric points: $(\pm x, \pm y)$ and $(\pm y, \pm x)$, cutting computations by 87.5%.

3.3 3×3 Homogeneous Transformation Matrices

Translation is an affine operation ($x' = x + t_x$) that cannot be represented in a 2×2 matrix. In 3D projective homogeneous coordinates $[x, y, 1]^T$:

Composite M = T(tx, ty) × R(θ) × Sh(shx, shy) × S(sx, sy)
[ x' ] [ cosθ·sx - sinθ·shy -sinθ·sy + cosθ·shx tx ] [ x ]
[ y' ] = [ sinθ·sx + cosθ·shy cosθ·sy + sinθ·shx ty ] [ y ]
[ 1 ] [ 0 0 1 ] [ 1 ]

3.4 Rotation Around an Arbitrary Pivot Point

To rotate an object around joint $(x_p, y_p)$ rather than origin $(0, 0)$:

M_pivot = T(x_p, y_p) × R(θ) × T(-x_p, -y_p)

3.5 Hierarchical Forward Kinematics

Parent-child joint chaining ensures child limbs inherit parent motion:

M_world(child) = M_world(parent) × M_local(child)
